# ข้อมูล

## raw/ — รายงานจาก IT (ไม่เก็บใน git)

วาง "รายงานการจ่ายยาผู้ป่วยใน IPD" ที่ได้จาก IT ไว้ที่นี่ ตั้งชื่อไฟล์ตามช่วงวันที่ เช่น `2569-10_ipd-dispensing.xlsx`

โฟลเดอร์นี้ถูกตั้งไว้ใน `.gitignore` ไม่ให้เข้า git เพราะรายงานแบบรายวันอาจมีข้อมูลระดับผู้ป่วย ถ้า IT ส่งแบบ "สรุปยอดรวมต่อยา" ที่ไม่มีข้อมูลผู้ป่วยเลย ค่อยพิจารณาเก็บเข้า git ทีหลัง

## reference/ — ตารางอ้างอิง (เก็บใน git)

ตารางที่ทำครั้งเดียวตอนเริ่ม แล้วแก้เมื่อมีการเปลี่ยนแปลง (PRD ข้อ 4–5) แต่ละแถวคือยา 1 ตัว ข้อมูลที่ต้องมี:

- ชื่อยาตามรายงาน IT (เช่น `**AMLODIPINE **(C) 10 mg.`)
- ชื่อที่ OPD ใช้ในใบเบิก (เช่น `Amlo 10`)
- หน่วยย่อย (เม็ด / แอมป์ / ไวอัล / ขวด)
- ขนาดบรรจุ: 1 กล่องมีกี่หน่วยย่อย (เช่น 100)
- สต็อกที่ IPD ไหม (ใช่ / ไม่)
- ยาห้ามขาด / HAD (ใช่ / ไม่)
- ที่เก็บ (ตู้เก็บยา / ชั้นวางยา / ลิ้นชักยา)
