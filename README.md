# ระบบสต็อกยา IPD

เครื่องมือช่วยห้องยาผู้ป่วยใน (IPD) คำนวณยอดยาที่ควรมีเก็บ ยอดที่ต้องเบิกในแต่ละรอบ และออกรายการเบิกในรูปแบบเดียวกับใบเบิกของห้องยา OPD เพื่อให้ OPD รวมเข้าใบเบิกคลังยาได้ทันที

- โจทย์และขอบเขตทั้งหมด: [docs/PRD.md](docs/PRD.md) (ต้นฉบับคือเอกสาร "PRD IPD stock" ใน Google Docs)
- รอบแรกเป็นไฟล์ Excel / Google Sheets ที่คำนวณให้ ยังไม่ตัดสต็อกอัตโนมัติ ไม่เชื่อมระบบโรงพยาบาล และไม่ติดตามวันหมดอายุ

## สถานะ (15 พ.ย. 2569)

ได้คำตอบข้อ 7 จากเจ้าหน้าที่ IPD แล้วบางส่วน ยังไม่เริ่มทำไฟล์คำนวณ

**ที่ตกลงได้แล้ว**

| เรื่อง | คำตอบ |
| :- | :- |
| รอบเบิก | สัปดาห์ละครั้ง OPD เบิกจากคลังวันอังคาร ยามาถึงวันพุธ ประมาณ 14.00 น. |
| วันเผื่อ | 3–5 วัน |
| ยาห้ามขาด | HAD Inj 11 รายการ (ใช้เติม Emer box) |
| ที่เก็บยาที่ต้องนับ | ตู้เก็บยา ชั้นวางยา ลิ้นชักยา |
| คนนับ | เจ้าพนักงานเภสัชกรรมห้องยา IPD (มี 1 คน) ใช้เวลา 30 นาที – 1 ชั่วโมง |
| คนตรวจ | เภสัชกรประจำงานผู้ป่วยใน |
| เครื่องพิมพ์ | IPD ไม่มีเครื่องที่พร้อมใช้ ไปพิมพ์ที่คลังหรือห้อง OPD |

**ยังต้องตัดสินใจ**

- [ ] OPD ยินดีรวมรายการไหม ต่อท้ายใบเดิมหรือแนบใบแยก (ต้องถามผู้รับผิดชอบการเบิกของ OPD)
- [ ] ยาตัวไหนต้องสต็อก และใช้ข้อมูลการใช้ยาย้อนหลัง 3 เดือนหรือ 1 ปี
- [ ] วันเผื่อจะใช้ 3 หรือ 5 วัน และยา HAD ใช้วันเผื่อมากกว่ายาทั่วไปไหม
- [ ] ตัวเลขเป้าหมายในข้อ 8 (เดินไปเอายากี่ครั้ง/สัปดาห์, ทำรายการเบิกกี่นาที)
- [ ] ขอข้อมูลการจ่ายยาจาก IT ย้อนหลังอย่างน้อย 3 เดือน
- [ ] ทำตารางยา: ชื่อในรายงาน IT ↔ ชื่อที่ OPD ใช้ ↔ ขนาดบรรจุ

**ข้อสังเกตสำหรับสูตรคำนวณ (ร่าง รอคุยกัน)** IPD นับยาวันอังคาร แต่ยามาถึงวันพุธบ่าย ยาที่เหลือตอนนับจึงต้องพอใช้อีก 1 วันก่อนของใหม่มา และของใหม่ต้องพอถึงวันพุธถัดไป ดังนั้นจำนวนวันในสูตรน่าจะเป็น 7 + 1 + วันเผื่อ ไม่ใช่แค่ 7 + วันเผื่อ
