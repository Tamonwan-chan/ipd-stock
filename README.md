# ระบบสต็อกยา IPD

เครื่องมือช่วยห้องยาผู้ป่วยใน (IPD) คำนวณยอดยาที่ควรมีเก็บ ยอดที่ต้องเบิกจากคลังทุก 2 สัปดาห์ (ใบเบิกหรือใบส่งคืน) และรายการยาที่ใช้น้อยซึ่งไปขอจากห้องยา OPD แทน

- โจทย์และขอบเขตทั้งหมด: [docs/PRD.md](docs/PRD.md) (ต้นฉบับคือเอกสาร "PRD IPD stock" ใน Google Docs)
- การออกแบบระบบ: [docs/DESIGN.md](docs/DESIGN.md) ใช้ Google Sheets เป็นฐานข้อมูล และ Google Apps Script ทำหน้าจอนับยา ตรวจรายการ และพิมพ์ใบเบิก
- รอบแรกยังไม่ตัดสต็อกอัตโนมัติ ไม่เชื่อมระบบโรงพยาบาล และไม่ติดตามวันหมดอายุ

## สถานะ (16 พ.ย. 2569)

หน้าเว็บใช้งานได้แล้ว (ตอนนี้เปิดได้เฉพาะเจ้าของ) หน้าตาใหม่ 18 พ.ย. 2569: เข้าสู่ระบบด้วยบัญชีของแต่ละคน เมนูด้านซ้าย มีหน้าหลัก รายการยาพร้อมบัตรคุมยา เบิกยา (จากคลังหรือจาก OPD) ตรวจรับยาพร้อมวันหมดอายุ นำเข้าข้อมูล HOSxP และป้ายสูงสุด/ต่ำสุด (ดู [วิธีใช้หน้าเว็บ](#วิธีใช้หน้าเว็บ)) ทุกการแก้ไขบันทึกชื่อผู้แก้และเวลา เภสัชกำหนดได้ว่ายาตัวไหนเบิกจากคลังหรือขอจาก OPD ที่ รายการยา › แก้ไขข้อมูลยา › เบิกจาก ข้อมูลในระบบตอนนี้คือการใช้ยา ส.ค.–ต.ค. 2569 เรื่องที่ยังเปิดอยู่ดูได้ที่ [Issues](https://github.com/Tamonwan-chan/ipd-stock/issues)

**เปลี่ยนแปลง 16 พ.ย. 2569**

- IPD เบิกจากคลังเอง **ทุก 2 สัปดาห์** ด้วยใบเบิกหรือใบส่งคืน ไม่ได้รวมในใบเบิกของ OPD แล้ว
- ยาที่มีการใช้ **อย่างน้อยสัปดาห์ละครั้ง** (อย่างน้อย 1 ใน 7 วันของข้อมูล 3 เดือน) ให้สต็อกและเบิกจากคลัง ยาที่ใช้น้อยกว่านั้นไม่ต้องสต็อก ให้ขอจาก OPD **เดือนละครั้ง** แยกเป็นอีกรายการ จำนวนที่แนะนำ = ใช้เฉลี่ยใน 30 วัน จะขอหรือไม่ก็ได้ ยา HAD เบิกจากคลังเสมอ ยาราคาสูงที่ใช้ไม่บ่อยให้ขอจาก OPD จนกว่าเภสัชจะกำหนดยอดให้สต็อก
- เขียนจำนวนเป็นหน่วยย่อย (เม็ด ขวด ฯลฯ) พร้อมหน่วยนับ ไม่ปัดเป็นกล่อง
- **ไม่ใช้ขนาดแพ็คแล้ว** เดิมจะใช้เกณฑ์ "ช่วง 2 สัปดาห์ที่ใช้มากสุดถึง 80% ของ 1 แพ็ค → เบิกจากคลัง" แต่ขนาดแพ็คของคลังเปลี่ยนบ่อย และ IPD เบิกเป็นหน่วยย่อยอยู่แล้ว จึงใช้ความถี่การใช้ยาแทน

**สูตรคำนวณ (ปรับจาก PRD ข้อ 5)** จากข้อมูลจริง 3 เดือน สูตร "ใช้ต่อวัน × จำนวนวัน" ทำให้ยาขาดประมาณ 1 ใน 5 สัปดาห์ เพราะยาส่วนใหญ่ใช้ไม่สม่ำเสมอ จึงเปลี่ยนเป็นสูตรมาตรฐานของการเบิกแบบนับเป็นรอบ เบิกจากคลังทุก 2 สัปดาห์:

> **ยอดที่ควรมี = ใช้เฉลี่ยต่อวัน × 21 วัน + ยาสำรอง**

**ทำไมต้อง 21 วัน** ยาที่มีหลังเบิกต้องพอใช้จนถึงวันที่ยารอบถัดไปมาถึง ไม่ใช่แค่ถึงวันนับครั้งหน้า

```
วันที่ 0    นับยา + เขียนใบเบิก      ← ตัดสินใจยอดเบิกตรงนี้
วันที่ 1    ยารอบนี้มาถึง
  ...      ผู้ป่วยใช้ยาไปเรื่อย ๆ
วันที่ 14   นับยารอบถัดไป
วันที่ 15   ยารอบถัดไปมาถึง          ← เติมยาได้อีกครั้งเร็วที่สุดวันนี้
```

ยาที่นับได้ + ยาที่เบิกครั้งนี้ ต้องพอใช้ตั้งแต่วันที่ 0 ถึงวันที่ 15 = 14 วัน (รอบเบิก) + 1 วัน (รอยาจากคลัง) + 1 วัน (วันนับเอง) = 16 วัน บวกเผื่อยามาช้า 5 วัน (ตกลงกับ IPD 17 พ.ย.) รวม 21 วัน ถ้าวันนับ วันที่ยามาถึง หรือวันเผื่อเปลี่ยน จำนวนวันจะเปลี่ยนตามเอง (แก้ได้ในแท็บ Settings)

**ทำไมต้องมียาสำรอง** ค่าเฉลี่ยคือค่ากลาง ประมาณครึ่งหนึ่งของรอบจะใช้มากกว่าค่าเฉลี่ย ถ้าเบิกแค่ค่าเฉลี่ยยาจะขาดบ่อย จึงบวกยาสำรองตามความไม่สม่ำเสมอของยาแต่ละตัว ยาที่ใช้สม่ำเสมอทุกวันแทบไม่ต้องสำรอง ยาที่บางวันไม่ใช้เลย บางวันใช้มาก ได้สำรองมาก ตั้งไว้ให้พอใช้ประมาณ 95% ของรอบ (ยา HAD 99% และไม่น้อยกว่ายอดที่เคยใช้มากที่สุดใน 21 วัน)

| | ยาที่ใช้สม่ำเสมอ | ยาที่ใช้ไม่สม่ำเสมอ |
| :- | :- | :- |
| การใช้ | วันละ 10 เม็ดทุกวัน | เฉลี่ยวันละ 2 แต่บางวัน 0 บางวัน 8 |
| ใช้เฉลี่ย × 21 วัน | 210 | 42 |
| ยาสำรอง | 0 | 31 |
| **ยอดที่ควรมี** | **210** | **73** |

จากการทดสอบกับข้อมูลจริง (คำนวณจาก ส.ค.–ก.ย. แล้วเทียบกับการใช้จริงเดือน ต.ค.) เบิกทุก 2 สัปดาห์ยังมีประมาณ 9% ของรายการในแต่ละรอบที่ต้องไปขอเพิ่มจาก OPD ยอดต่ำสุด (ด้านล่าง) มีไว้เตือนกรณีนี้ สูตรเต็มอยู่ใน [docs/DESIGN.md](docs/DESIGN.md) ข้อ 5

**ยอดสูงสุดและต่ำสุด (max / min)** ยอดสูงสุด = ยอดที่ควรมีข้างบน ทุกรอบเบิกเติมให้ถึงยอดนี้ ยอดต่ำสุด = ใช้เฉลี่ยต่อวัน × 7 วัน + ยาสำรอง (7 วัน = วันนับยาถึงวันที่ยารอบนี้มาถึง 2 วัน + เผื่อยามาช้า 5 วัน) ถ้าเหลือน้อยกว่ายอดต่ำสุด ยาจะหมดก่อนยาจากคลังมาถึง ให้ไปขอจาก OPD วันนั้นเลย ยา HAD ยอดต่ำสุดไม่น้อยกว่ายอดที่เคยใช้มากที่สุดใน 7 วัน เภสัชกำหนดยอดต่ำสุดเองได้ในคอลัมน์ min_override ของแท็บ Drugs (ใส่ 0 = ไม่ต้องเตือน)

## วิธีใช้หน้าเว็บ

เปิดลิงก์หน้าเว็บจากเมนู **IPD › เปิดหน้าเว็บ (ลิงก์)** ใน Google Sheet "IPD Stock" แล้วเข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่านของตัวเอง (ผู้ดูแลระบบสร้างบัญชีให้ เปลี่ยนรหัสผ่านเองได้ที่มุมซ้ายล่าง) ใช้เครื่องร่วมกันให้กด ออกจากระบบ ทุกครั้ง

**ทุก 2 สัปดาห์ (เบิกจากคลัง)**

1. **นำเข้าข้อมูล HOSxP**: ลากไฟล์รายงานการจ่ายยาผู้ป่วยในจาก HOSxP มาวาง ตรวจตัวอย่าง แล้วกด นำเข้า โปรแกรมคำนวณยอดสูงสุด/ต่ำสุดใหม่ให้
2. **เบิกยา › เบิกจากคลัง** กด **พิมพ์ใบนับยา** ใบนับมีทั้งยาที่เบิกคลัง (พร้อมยอดสูงสุด/ต่ำสุด) และยาที่ขอจาก OPD ที่เก็บไว้ที่ IPD ไปนับที่ชั้นยาแล้วเขียนจำนวนลงใบ
3. กลับมาที่คอมพิวเตอร์ กด เริ่มรอบนับ แล้วใส่จำนวนที่นับได้ตามใบนับ โปรแกรมแสดง ควรเบิก ให้ทันทีและบันทึกเอง ช่องว่าง = ยังไม่นับ, 0 = หมด แก้ยอดได้ที่ เบิกจริง (ใส่เหตุผล) ถ้าจะเบิกเป็นกล่อง ใส่ กล่อง และ ต่อกล่อง โปรแกรมคิด เบิกจริง = กล่อง × ต่อกล่อง และจำจำนวนต่อกล่องไว้ใช้รอบหน้า ยาที่ขอจาก OPD ใส่แค่จำนวนคงเหลือ แถวสีแดง = ต่ำกว่ายอดต่ำสุด ให้ขอด่วนจาก OPD วันนี้
4. กด **อนุมัติรอบนี้** แล้วไปที่ **ใบเบิก** กรอกเล่มที่/เลขที่ แล้ว พิมพ์ใบเบิก ส่งคลัง (รายการที่เบิกเป็นกล่องแสดงเป็น 1x1000 และจ่ายหรือรับคืนเป็นจำนวนกล่อง)
5. เมื่อยาจากคลังมาถึง ไปที่ **ตรวจรับยา** กดเลือกใบเบิกที่ตรงกับยาที่ได้รับ (มีเฉพาะใบเบิกที่อนุมัติแล้ว) เทียบกับใบจ่ายจากคลัง ใส่จำนวนที่ได้รับจริงทุกรายการ (ได้ครบกด ครบ ไม่ได้รับเลยใส่ 0) และวันหมดอายุ ถ้ายาตัวเดียวมีหลายวันหมดอายุ กด + วันหมดอายุ เพิ่ม กด บันทึกร่าง ได้ทุกเมื่อ ตรวจครบแล้วกด **ยืนยันรับเข้าคลัง** โปรแกรมออกเลขใบรับ (ร.69/0001) และแก้จำนวนไม่ได้อีก ยาที่คลังไม่ได้ให้จะไม่ค้างไว้ ถ้ายังต้องการให้เบิกในใบเบิกถัดไป

เลขที่เอกสาร: ใบเบิกได้เลข บ.69/0001 เมื่ออนุมัติรอบ (พิมพ์ในช่องเลขที่ของใบเบิกให้) ใบขอจาก OPD ได้เลขเมื่อบันทึก ใบรับได้เลข ร.69/0001 เมื่อยืนยันรับเข้าคลัง เลขเริ่ม 0001 ใหม่ทุกปี

**เบิกจาก OPD**

- **เบิกยา › เบิกจาก OPD**: ติ๊กยาที่จะขอ จำนวนที่แนะนำ = ใช้เฉลี่ยใน 1 เดือน ลบคงเหลือที่นับรอบนี้ แก้ได้ เลือกประเภท ประจำเดือน หรือ ด่วน แล้วกด บันทึกและพิมพ์ ยาที่เบิกคลังแต่ต่ำกว่ายอดต่ำสุด กด ขอด่วนจาก OPD ที่หน้าหลักได้เลย
- ได้ยาแล้ว ไปที่ **ตรวจรับยา** กดเลือกใบเบิก OPD ใส่จำนวนที่ได้รับและวันหมดอายุ แล้วกด ยืนยันรับเข้าคลัง (เหมือนยาจากคลัง)

**รายการยา**: ค้นหายา ดูบัตรคุมยาของแต่ละตัว (ยอดนับ การเบิก การรับ และวันหมดอายุที่มีในสต็อก ลบวันหมดอายุที่ใช้หมดแล้วได้) เพิ่มยาใหม่หรือแก้ข้อมูลยาได้ (ชื่อที่ใช้เบิก หน่วย หมายเลขพัสดุ จำนวนต่อกล่อง เบิกจากคลังหรือ OPD ยาห้ามขาด ยอดสูงสุด/ต่ำสุดที่เภสัชกำหนดเอง)

**ป้ายสูงสุด/ต่ำสุด**: พิมพ์ไปติดที่ชั้นยา ควรพิมพ์ใหม่ทุกครั้งที่นำเข้าข้อมูลการใช้ยาใหม่

**ผู้ดูแลระบบ** มีเมนูเพิ่ม: **ผู้ใช้งาน** (เพิ่มเจ้าหน้าที่ ตั้งรหัสผ่านใหม่ ปิดใช้งาน) และ **ประวัติการแก้ไข** (ใครแก้อะไร เมื่อไร) บัญชีผู้ดูแลระบบบัญชีแรกสร้างจากเมนู **IPD › สร้างบัญชีผู้ดูแลระบบ / ตั้งรหัสใหม่** ใน Google Sheet

## โครงสร้างโฟลเดอร์

```
docs/        เอกสารโจทย์ (PRD) และการออกแบบ (DESIGN)
data/raw/    รายงานจาก IT (ไม่เก็บใน git ดู data/README.md)
src/         โค้ด Apps Script (Calc.js คำนวณ, Schema.js + Db.js ฐานข้อมูลใน Sheet, Import.js นำเข้าข้อมูล, Api.js + ui/ หน้าเว็บ, Code.js เมนู)
test/        ชุดทดสอบส่วนคำนวณ (npm test)
tools/       เครื่องมือทดสอบสูตรกับข้อมูลจริง (npm run backtest)
```

repo นี้เป็นสาธารณะ เก็บเฉพาะโค้ดและเอกสาร ข้อมูลยาและการใช้ยาอยู่ใน Google Sheet เท่านั้น
