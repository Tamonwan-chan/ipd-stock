# ระบบสต็อกยา IPD

เครื่องมือช่วยห้องยาผู้ป่วยใน (IPD) คำนวณยอดยาที่ควรมีเก็บ ยอดที่ต้องเบิกจากคลังทุก 2 สัปดาห์ (ใบเบิกหรือใบส่งคืน) และรายการยาที่ใช้น้อยซึ่งไปขอจากห้องยา OPD แทน

- โจทย์และขอบเขตทั้งหมด: [docs/PRD.md](docs/PRD.md) (ต้นฉบับคือเอกสาร "PRD IPD stock" ใน Google Docs)
- การออกแบบระบบ: [docs/DESIGN.md](docs/DESIGN.md) ใช้ Google Sheets เป็นฐานข้อมูล และ Google Apps Script ทำหน้าจอนับยา ตรวจรายการ และพิมพ์ใบเบิก
- รอบแรกยังไม่ตัดสต็อกอัตโนมัติ ไม่เชื่อมระบบโรงพยาบาล และไม่ติดตามวันหมดอายุ

## สถานะ (16 พ.ย. 2569)

มีส่วนคำนวณ (Calc.js) และเครื่องมือทดสอบกับข้อมูลจริงแล้ว ยังไม่ได้ทำหน้าจอนับยา เรื่องที่ยังเปิดอยู่ดูได้ที่ [Issues](https://github.com/Tamonwan-chan/ipd-stock/issues)

**เปลี่ยนแปลง 16 พ.ย. 2569**

- IPD เบิกจากคลังเอง **ทุก 2 สัปดาห์** ด้วยใบเบิกหรือใบส่งคืน ไม่ได้รวมในใบเบิกของ OPD แล้ว
- ยาที่ใช้ไม่ถึง **1 แพ็ค (เช่น 1 กล่อง) ต่อรอบ 2 สัปดาห์** ให้ไปขอจาก OPD แทน แยกเป็นอีกรายการ จะขอหรือไม่ก็ได้ ยาที่ใช้ถึง 1 แพ็คขึ้นไปให้เบิกจากคลัง
- เขียนจำนวนเป็นหน่วยย่อย (เม็ด ขวด ฯลฯ) พร้อมหน่วยนับ ยังไม่ปัดเป็นกล่อง ถ้าเจ้าหน้าที่ IPD ต้องการแบบอื่นค่อยปรับ

**ที่ตกลงได้แล้ว**

| เรื่อง | คำตอบ |
| :- | :- |
| รอบเบิก | เบิกจากคลังทุก 2 สัปดาห์ (เปลี่ยนจากสัปดาห์ละครั้งตามรอบ OPD) |
| วันเผื่อ | 3–5 วัน |
| ยาห้ามขาด | HAD Inj 11 รายการ (ใช้เติม Emer box) |
| ที่เก็บยาที่ต้องนับ | ตู้เก็บยา ชั้นวางยา ลิ้นชักยา |
| คนนับ | เจ้าพนักงานเภสัชกรรมห้องยา IPD (มี 1 คน) ใช้เวลา 30 นาที – 1 ชั่วโมง |
| คนตรวจ | เภสัชกรประจำงานผู้ป่วยใน |
| เครื่องพิมพ์ | IPD ไม่มีเครื่องที่พร้อมใช้ ไปพิมพ์ที่คลังหรือห้อง OPD |
| รูปแบบใบเบิก | ใบเบิกหรือใบส่งคืนของคลัง เขียนเป็นหน่วยย่อยพร้อมหน่วยนับ ไม่ต้องแปลงเป็นกล่อง (เช่น Vitamin B complex 1500 เม็ด) |
| ข้อมูลการใช้ยา | ได้จาก HOSxP รายวัน 1 ส.ค. – 31 ต.ค. 2569 รวมยากลับบ้าน (HM) ซึ่งจ่ายจากสต็อก IPD (เก็บใน Google Sheet ไม่อยู่ใน repo) |
| ยาน้ำคิดเป็น ml | นับและเบิกเป็นขวดเต็ม เช่น KCl elixir ขวดละ 240 ml |

**ยังต้องตัดสินใจ** (รายละเอียดใน [docs/DESIGN.md](docs/DESIGN.md) ข้อ 9)

- [ ] นับยาวันไหน และคลังส่งยามาถึงวันไหน
- [ ] รายการยาที่ IPD ไปขอจาก OPD ตอนนี้ (เพื่อเทียบกับเกณฑ์ 1 แพ็ค)
- [ ] ขนาดแพ็คของยาแต่ละตัว (ตอนนี้มี 26 รายการจากใบจ่ายของคลังและใบเบิก)
- [ ] คลังมีหมายเลขพัสดุของยาแต่ละตัวไหม
- [ ] ต้องเผื่อยามาช้าไหม เผื่อทุกตัวหรือเฉพาะยา HAD
- [ ] เจ้าหน้าที่มีบัญชี Google ไหม และจะใช้มือถือนับยาได้ไหม
- [ ] ขนาดขวดของยาน้ำที่ HOSxP นับเป็น ml (KCl elixir = 240 ml แล้ว ที่เหลือ: Berodual sol, Salbutamol sol, Lidocaine 2%)
- [ ] ยาราคาสูงที่ใช้ไม่บ่อย (~20 รายการ) จะสต็อกขั้นต่ำกี่ชิ้น
- [ ] ตัวเลขเป้าหมายในข้อ 8 (เดินไปเอายากี่ครั้ง/สัปดาห์, ทำรายการเบิกกี่นาที)

**สูตรคำนวณ (ปรับจาก PRD ข้อ 5)** จากข้อมูลจริง 3 เดือน สูตร "ใช้ต่อวัน × จำนวนวัน" ทำให้ยาขาดประมาณ 1 ใน 5 สัปดาห์ เพราะยาส่วนใหญ่ใช้ไม่สม่ำเสมอ จึงเปลี่ยนเป็นสูตรมาตรฐานของการเบิกแบบนับเป็นรอบ: ยอดที่ควรมี = ใช้เฉลี่ยต่อวัน × 16 วัน + ยาสำรอง โดยยาสำรองมากหรือน้อยตามความไม่สม่ำเสมอของการใช้ยาแต่ละตัว (16 วัน = รอบ 2 สัปดาห์ บวกเวลาตั้งแต่วันนับยาถึงวันที่ยามาถึง) เบิกจากคลังทุก 2 สัปดาห์ รายละเอียดใน [docs/DESIGN.md](docs/DESIGN.md) ข้อ 5

## โครงสร้างโฟลเดอร์

```
docs/        เอกสารโจทย์ (PRD) และการออกแบบ (DESIGN)
data/raw/    รายงานจาก IT (ไม่เก็บใน git ดู data/README.md)
src/         โค้ด Apps Script (ตอนนี้มีส่วนคำนวณ Calc.js)
test/        ชุดทดสอบส่วนคำนวณ (npm test)
tools/       เครื่องมือทดสอบสูตรกับข้อมูลจริง (npm run backtest) และแยกยาคลัง/OPD ตามเกณฑ์ 1 แพ็ค (npm run pack-rule)
```

repo นี้เป็นสาธารณะ เก็บเฉพาะโค้ดและเอกสาร ข้อมูลยาและการใช้ยาอยู่ใน Google Sheet เท่านั้น
